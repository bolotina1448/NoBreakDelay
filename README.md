# No Break Delay

Клиентский мод для **Minecraft Forge 1.8.9**.

## Функции

### Hit Delay Fix — включён по умолчанию

В 1.8 после клика по воздуху клиент ставит штраф 10 тиков (0,5 с): пока он идёт,
клики и удержание ЛКМ игнорируются. Если кликать, после каждого сломанного блока
следующий клик уходит в воздух, и ломание нового блока начинается с паузой.
Мод снимает этот штраф, как HitDelayFix. Серверу это не видно: пакеты те же,
что у игрока, который просто не промахнулся.

### Legit Break Fix — включён по умолчанию

После поломки блока клиент ставит задержку 5 тиков, но в ванилле этот счётчик
уменьшается **только пока ЛКМ зажата на блоке**. Отпустил кнопку — счётчик замирает,
и следующий блок (даже через 10 секунд) первые 5 тиков не ломается.

Мод заставляет счётчик идти по времени. Если между блоками прошло 250 мс и больше,
новый блок начинает ломаться сразу. При ломании подряд ванильный минимум 5 тиков
между блоками сохраняется — такие же тайминги пакетов может выдать и обычный клиент
(например, если после поломки подержать ЛКМ на соседнем блоке).

### No Break Delay — выключен по умолчанию

Обнуляет ванильную задержку 5 тиков (250 мс) между сломанным блоком и началом
ломания следующего. У обычного клиента так не бывает, сервер это видит.
**Только для одиночной игры** — на PvP-серверах за это банят.

### Blockhit Sound — включён по умолчанию

Звук наковальни, когда по тебе попали, а **сервер** в этот момент засчитал блок мечом.
Мод не гадает по таймерам и пингу: флаг блока своего игрока в 1.8.9 выставляет только
сервер, а пакеты приходят строго в том порядке, в котором сервер их отправил. Поэтому
сравнение идёт по порядку пакетов, и пинг с его скачками на результат не влияет.
Удар сервер шлёт сразу, а флаг — в конце тика, так что мод дожидается конца пачки
пакетов этого тика и только потом решает.

Если блок переключился в том же серверном тике, что и удар, узнать порядок нельзя —
тогда звука нет (лучше промолчать, чем соврать). Удары без взмаха рядом (огонь, падение,
стрелы) не оцениваются. Включи лог в чат, чтобы видеть результат каждого удара.

Мод только читает пакеты, которые сервер и так присылает: в игре ничего не меняет
и серверу ничего не отправляет.

Все функции включаются и выключаются клавишами в
*Настройки → Управление → No Break Delay* (по умолчанию не назначены).

## Установка

Скачай jar из раздела **Releases** и положи в папку `mods`
(Forge 1.8.9 или LabyMod с Forge).

## Сборка

```
./gradlew build
```

Готовый jar — в `build/libs/`. Сборка также идёт автоматически через GitHub Actions.

## Важно

Правила серверов про моды отличаются. Перед игрой на сервере проверь, разрешены ли там такие моды.
