# No Break Delay

Клиентский мод для **Minecraft Forge 1.8.9**, который убирает ванильную задержку
в 5 тиков (250 мс) между сломанным блоком и началом ломания следующего.

## Как работает

После поломки блока `PlayerControllerMP` выставляет `blockHitDelay = 5`, и следующие
5 тиков удары по блоку не засчитываются. Мод обнуляет этот счётчик каждый клиентский
тик, поэтому следующий блок начинает ломаться сразу. Скорость самого ломания не меняется.

Вкл/выкл — клавиша в *Настройки → Управление → No Break Delay* (по умолчанию не назначена).

## Установка

Скачай `nobreakdelay-1.0.0.jar` из раздела **Releases** и положи в папку `mods`
(Forge 1.8.9 или LabyMod с Forge).

## Сборка

```
./gradlew build
```

Готовый jar — в `build/libs/`. Сборка также идёт автоматически через GitHub Actions.

## Важно

На многих серверах (Hypixel и др.) моды, дающие преимущество, запрещены правилами.
Используй там, где это разрешено.
